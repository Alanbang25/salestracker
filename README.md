# Salestracker

Web-App (Standalone, läuft komplett im Browser), öffentlich nutzbar über GitHub Pages.
Änderungen am Code nur durch den Repo-Inhaber. Daten werden lokal im Browser des jeweiligen
Nutzers gespeichert (kein gemeinsames Backend — jede Person hat ihre eigene lokale Kopie).

## Spesen-App (eigenständig)
Eigene App unter `/spesen/` → https://alanbang25.github.io/salestracker/spesen/
Ausgaben, Agentur-Rechnung, Salden je Mitarbeiter, Excel-/PDF-Report. Installierbar aufs Handy
(„Zum Home-Bildschirm“), funktioniert offline. Daten liegen lokal im Browser → regelmäßig Backup ziehen.
